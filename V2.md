# Self-Debrid v2

Self-Debrid started as a small AllDebrid-compatible bridge for Kodi. That proved the core idea, but the current architecture only resolves links that another addon has already discovered.

Version 2 changes the responsibility of the project.

Self-Debrid v2 will be a self-hosted streaming engine that can discover candidate streams, normalize and rank them, download or cache the selected file, and expose it to multiple clients.

## Product direction

The v2 pipeline is:

    Stremio / Kodi / API
            |
            v
       Self-Debrid Core
            |
            +-- Discovery providers
            +-- Normalization
            +-- Deterministic ranking
            +-- Resolver / download engine
            +-- Local cache
            +-- HTTP streaming
            |
            v
       qBittorrent / JDownloader / direct HTTP

Stremio becomes a first-class client instead of forcing all clients through an AllDebrid compatibility layer. Kodi compatibility remains important and the current implementation stays available during the migration.

## Why the change

The legacy implementation cannot improve source quality because it receives an already selected link. It also contains download and client assumptions in the same path, making it difficult to add source aggregation, correct episode selection, persistent cache metadata and robust streaming.

The v2 core separates those concerns.

## Initial scope

The first usable v2 should:

- expose a native Stremio stream resource for IMDb IDs;
- accept multiple pluggable discovery providers;
- normalize results to one StreamCandidate model;
- deduplicate and rank candidates deterministically;
- select the correct file inside movie and season torrents;
- stream through qBittorrent with correct HTTP range behavior;
- persist cache and torrent/file metadata in SQLite;
- preserve the existing Kodi/AllDebrid path while it is migrated.

## Non-goals for the first release

- maintaining dozens of site-specific HTML scrapers;
- requiring PostgreSQL or Redis for a home installation;
- replacing Stremio metadata/catalog addons;
- deleting the current Kodi implementation before feature parity exists.

## Development status

Foundation started on the v2-development branch.

The first commit introduces the v2 domain contracts, provider registry, deterministic ranking primitives, Stremio request parsing/manifest helpers, tests, architecture documentation and agent development rules.
