# Self-Debrid v2

Self-Debrid v2 is a standalone implementation, not an incremental runtime
migration of the Kodi bridge. `main` retains stable v1 and `v1-kodi` retains its
maintenance line. Only `v2-development` contains this new application. Legacy
files have been removed from this branch; nothing is archived inside its tree.
Draft PR #2 remains open for review and must not be merged.

## Product direction

The intended pipeline is:

    Stremio / future Kodi / CLI
                |
           application core
                |
        discovery providers
                |
       normalization + deduplication
                |
         deterministic ranking
                |
        [future file selection]
        [future qBittorrent sessions]
        [future SQLite + HTTP streaming]

The working slice stops at ranked discovery results. It includes a standalone
installable package, CLI, validated domain models, bounded provider execution,
Torznab/Prowlarr capability-aware searches, release parsing, fixture tests and CI.
Stremio IMDb parsing and manifest construction are helpers only; Stremio playback
and an HTTP addon server are not implemented.

## Subsequent work

After Lead Developer review, add native Stremio HTTP integration, then exact file
selection and qBittorrent streaming, persistence in SQLite, and a new Kodi adapter
around the v2 core. v1 remains available independently throughout this work.
Optional providers and direct-download resolvers come later. Do not start by
adding large scraper collections or heavyweight infrastructure.

See [architecture](docs/V2_ARCHITECTURE.md), [roadmap](docs/V2_ROADMAP.md) and the
[README](README.md) for current commands, dependencies and configuration.
