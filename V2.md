# Self-Debrid v2

Self-Debrid v2 is a standalone implementation, not an incremental runtime
migration of the Kodi bridge. `main` retains stable v1 and `v1-kodi` retains its
maintenance line. Only `v2-development` contains this new application. Legacy
files have been removed from this branch; nothing is archived inside its tree.
Draft PR #2 remains open for review and must not be merged.

## Product direction

The intended pipeline is:

    Stremio / future Kodi / CLI
                |
           application core
                |
        discovery providers
                |
       normalization + deduplication
                |
         deterministic ranking
                |
        [future file selection]
        [future qBittorrent sessions]
        [future SQLite + HTTP streaming]

The implemented slice includes ranked discovery and a native Stremio HTTP addon.
The stream-only manifest and movie/series routes call SearchService, then serialize
supported v1 torrent hashes and safe file indices for Stremio's torrent engine.
This is direct Stremio torrent playback, not Self-Debrid local video streaming.
Mixed malformed feed items are recoverable; download locators never become video
URLs; series results use conservative episode evidence. See the README for the
largest-file fallback and compatibility limits. Live Prowlarr/Stremio validation
remains outstanding; offline contract tests do not prove playback compatibility.

## Subsequent work

Stop after Phase 2 for Lead Developer review. Exact torrent metadata/file selection,
qBittorrent sessions and local HTTP streaming belong to Phase 3. SQLite persistence
and a new Kodi adapter follow later. Configure UI, other providers, direct-download
resolvers and deployment tooling are not included in the current iteration.

See [architecture](docs/V2_ARCHITECTURE.md), [roadmap](docs/V2_ROADMAP.md) and the
[README](README.md) for current commands, dependencies and configuration.
