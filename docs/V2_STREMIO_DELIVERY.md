# Phase 2 native Stremio delivery

## Scope

Implements the Lead Developer review at accepted foundation commit 83d44df and the
native Stremio HTTP addon. The existing v2 worktree is used; the original main
checkout and its user edits are preserved. main and v1-kodi remain unchanged at
9bcabbbb331dfeb10557dde19ce47e978a8840bc. Draft PR #2 stays open and unmerged.
No new PR/repository, public hosting or Phase 3 implementation is introduced.

## Architecture changes

- providers/torznab.py: recover individual bad items; one safe diagnostic summary
  with skipped count and at most five item positions. Document/auth/XML/HTTP errors
  still fail that provider. Recognize torrent locators and discard details links.
- domain/episode_selection.py: pure conservative episode evidence. SearchService
  filters before deduplication so wrong episodes cannot win representative metadata.
  The release parser does not infer coordinates from a pack/range's first episode;
  ambiguous names require explicit upstream attributes for a file mapping.
- adapters/stremio/streams.py: pure native v1 hash mapper, fileIdx 0–65535 when
  known, readable bounded metadata, no URL/trackers/passkeys/provider error output.
- adapters/stremio/http.py: injected SearchService, manifest/stream/health routes,
  sanitized JSON and CORS, no-store responses, safe failure counts and cancellation.
- infrastructure/bootstrap.py: shared CLI/HTTP composition with the existing
  provider configuration, registry bounds and ranking preferences.
- infrastructure/config.py and CLI: loopback host/port defaults, explicit LAN
  override, optional advertised base URL and self-debrid serve. Existing search
  command remains available. Raw serve access logs are disabled.
- Python package version 2.0.0.dev1; manifest SemVer 2.0.0-dev.1; stable addon ID
  com.selfdebrid.addon. No runtime dependency was added.

## Sample valid protocol responses

These use synthetic fixture hashes to demonstrate the schema. They are not
claims that these hashes resolve to playable content. Both objects below are
generated by the actual pure mapper.

Movie: GET /stream/movie/tt1234567.json

```json
{
  "streams": [
    {
      "infoHash": "1111111111111111111111111111111111111111",
      "name": "Self-Debrid \u00b7 1080p",
      "description": "Example.Movie.1080p.English\n1080p \u00b7 H.265\nLanguages: en\nSize: 2.00 GiB\nSeeders: 23\nProvider: fixture\nNative torrent playback; file index 0",
      "fileIdx": 0
    }
  ]
}
```

Episode: GET /stream/series/tt1234567:2:5.json

```json
{
  "streams": [
    {
      "infoHash": "4444444444444444444444444444444444444444",
      "name": "Self-Debrid \u00b7 1080p",
      "description": "Example.Show.S02E05.1080p\n1080p \u00b7 H.264\nLanguages: es\nSeeders: 12\nProvider: fixture\nNative torrent playback; file index 2",
      "fileIdx": 2
    }
  ]
}
```

When an eligible candidate has no file index, fileIdx is omitted and the
description explicitly states Stremio's largest-file selection. A valid search
with no supported results returns exactly {"streams": []} with HTTP 200.

## Policy and limitations for review

- This is native Stremio torrent discovery/playback handoff. Self-Debrid performs
  no torrent downloading, file inspection, video streaming or qBittorrent work.
- No live Prowlarr/client compatibility claim is made. The exact human procedure
  is [STREMIO_SMOKE_TEST.md](STREMIO_SMOKE_TEST.md).
- Without a known index, series candidates require one exact episode name and
  no pack/range markers. Stremio chooses the largest file; a misleading name,
  sample, extra or alternate version can still select incorrectly.
- Packs require an explicit usable index and matching episode mapping; index
  alone is insufficient. The mapping is trusted upstream data, not a verified
  torrent file list. Obvious name/attribute season/episode contradictions fail.
- v2-only hashes and hashless download locators are omitted from addon output.
  There is no torrent download to recover a missing hash or alias database.
- No tracker URLs are forwarded. Authenticated private-tracker playback is not
  supported by this hash-only mode; public peer discovery must work in Stremio.
- Stremio supplies IMDb IDs, not titles. Endpoints lacking the needed IMDb
  capabilities may work with CLI --title but return no addon streams.
- The CLI composes one endpoint; library composition supports several providers.
  Capabilities are instance-cached; only the first/default page is fetched.
- Locator recognition uses declared torrent MIME types and known URL shapes;
  it is not content verification. No locator can become a playable HTTP url.
- Health is process liveness, not upstream readiness. Provider failures preserve
  healthy results and are not exposed as raw response text.
- The existing provider timeouts bound each search window. No blanket HTTP
  deadline discards healthy results; providers must cooperate with cancellation.
- PUBLIC_ADDON_URL affects the startup address only. Non-loopback clients may
  require a trusted HTTPS reverse proxy. No auth system or proxy is installed.
- Configure UI, local HTTP streaming, cache persistence, Kodi adapter, SQLite,
  Docker, Torrentio and JDownloader remain unimplemented. Stop before Phase 3.
